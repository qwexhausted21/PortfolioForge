# ChangeLog — PortfolioForge v0.4.0-beta

## 🎨 Переработка интерфейса
- **Тёмная тема** — переключатель в шапке приложения, выбор сохраняется в локальном хранилище браузера, учитываются системные настройки (`prefers-color-scheme: dark`)
- **Индикатор работы** — спиннер на кнопке «Опубликовать на GitHub» и реальный прогресс-бар с процентами; сообщение об успехе отображается только после завершения публикации (прогресс 100 %), а не сразу после запуска
- **Кнопка «Отменить публикацию»** — появляется во время публикации, позволяет прервать процесс между этапами

## 🐞 Исправления багов
- **Выбор папки** — убрано ограничение «папка внутри домашней директории»; теперь можно выбрать любую папку на любом диске
- **Имя проекта из папки** — при выборе папки поле названия репозитория заполняется именем папки автоматически
- **Кириллица в имени репозитория** — при импорте из библиотеки и ручном добавлении по ссылке ошибка кодировки `latin-1` больше не возникает
- **Безопасность `.git`** — существующий `.git` в выбранной папке больше не удаляется безвозвратно; используется как есть
- **Отсутствие отчёта об ошибке публикации** — мёртвый `return JSONResponse` внутри фонового потока убран; ошибки фиксируются в логах

## ➕ Новые функции
- **Сохранение папки между запусками** — последний выбранный путь восстанавливается при старте приложения вместе с README
- **Валидация имени репозитория на бэкенде** — недопустимые символы отсекаются на сервере, а не только на фронтенде
- **Таймаут git-операций** (5 мин) — `git push` без сети больше не весит бесконечно
- **Генерация EXE** — сборка через PyInstaller, версия v0.4.0-beta

## 🔒 Безопасность
- Реальный GitHub Personal Access Token удалён из `.env` и заменён на placeholder (ротируйте токен, если он был скопирован до этого момента)
- Удалены отладочные probe-файлы из корня проекта
