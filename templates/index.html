Токен GitHub

Введите Personal Access Token (права repo). Токен сохранится в .env и не попадёт в коммиты.

Токен виден только вам, не передаётся на сторонние серверы.

Форма проекта

Через запятую — для бейджей в README.

При включении — код пушится в уже существующий репозиторий с этим именем.

Как это работает:

  • README.md генерируется автоматически с бейджами и инструкцией.
  • Создаётся публичный репозиторий под именем проекта (или обновляется существующий).
  • Проект коммитится и пушится на GitHub одной кнопкой.
  • Токен берётся из .env (GITHUB_TOKEN).
